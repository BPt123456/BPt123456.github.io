# assets 资源目录

此目录用于存放主页用到的静态资源。

## 简历 PDF（重要）

页面最下方的「下载我的简历 PDF」按钮指向本目录下的：

```
assets/resume.pdf
```

请将你的简历文件**重命名为 `resume.pdf`** 后放入本目录，下载入口即可正常工作。

> 说明：请自行把简历文件重命名为 `resume.pdf` 放入本目录。
> 若文件不存在，点击按钮会跳转到 404 页面；放入文件后即可正常下载。

## 其他可选资源

- `avatar.jpg` —— 头像图片（如需在 Hero 区展示）
- `works/` —— 作品截图或封面图
